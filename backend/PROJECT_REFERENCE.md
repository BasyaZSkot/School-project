# Справочник проекта MultiMarket

Этот документ описывает рабочий код приложения: его классы, методы, функции и основные обработчики интерфейса. Он дополняет краткое описание в README и руководство по парсерам в src/parcers/PARSER_GUIDE.md.

## Путь запроса через приложение

1. Страница поиска в static/app.js отправляет запрос на GET /api/search с текстом, номером страницы и идентификатором поисковой сессии.
2. Маршрут search в src/parcers/api.py проверяет параметры и вызывает MarketplaceSearchService.search.
3. Сервис параллельно запрашивает адаптеры Ozon, Wildberries и Яндекс Маркета. Ошибка одного источника не отменяет результаты остальных.
4. Каждый адаптер возвращает ProviderResult со списком Offer. Парсеры читают структурированные данные из публичного HTML, встроенного JSON состояния или настроенного партнёрского фида.
5. Сервис сопоставляет предложения разных площадок, сортирует карточки и отдаёт страницу. Поисковая сессия хранит уже найденные предложения до 10 минут, чтобы временный сбой источника не стирал выдачу.
6. Клиент добавляет карточки в список. При пустой странице из-за временного сбоя кнопка остаётся и предлагает повторить запрос с тем же offset.

Пользовательский размер страницы — до 50 карточек. Внутренние адаптеры могут принимать до MAX_PROVIDER_LIMIT=200 записей за вызов; это согласовано с PROVIDER_FETCH_CAP сервиса и предотвращает ошибку на следующих страницах, когда общий offset превышает 50.

## Сервер и HTTP API

### src/parcers/api.py

**Константы и объекты**

- **BACKEND_DIR** — корень backend относительно файла API.
- **STATIC_DIR** — каталог HTML, CSS и JavaScript интерфейса.
- **search_service** — общий экземпляр MarketplaceSearchService.
- **MARKETPLACE_DOMAINS** — список доменов, допустимых для ссылок на каждый маркетплейс.
- **app** — приложение FastAPI и его метаданные.

**Модели запросов**

- **BatchSearchRequest** — до десяти поисковых фраз и размер страницы.
- **MonitorCreate** — запрос на отслеживание товара: запрос, URL, площадка, название и интервал проверки.
- **MonitorUpdate** — поля, которые можно менять у мониторинга: активность и интервал.

**Функции и маршруты**

- **lifespan(app)** — при старте создаёт таблицы SQLite и запускает фоновый цикл мониторинга; при остановке подаёт ему сигнал и дожидается завершения.
- **home()** — отдаёт главную страницу поиска.
- **monitoring_page()** — отдаёт страницу списка отслеживаемых товаров.
- **history_page()** — отдаёт страницу истории цены.
- **sources_page()** — отдаёт страницу с состоянием и подключением источников.
- **health()** — возвращает состояние и версию сервиса для проверки доступности.
- **search(q, limit, offset, session_id)** — валидирует поисковые параметры и возвращает страницу предложений. session_id включает сохранение уже полученных результатов между кликами.
- **product_details(marketplace, product_url)** — сначала проверяет HTTPS, порт и домен ссылки, затем вызывает адаптер карточки; возвращает доступное описание, рейтинг, отзывы и характеристики либо безопасное сообщение об отсутствии данных.
- **batch_search(payload)** — запускает несколько поисков параллельно, но одновременно допускает не больше трёх; отдельная ошибка становится ошибкой только соответствующего запроса.
- **run_one(query)** — вложенная в batch_search функция: ограничивает параллелизм семафором и формирует результат либо краткий объект ошибки.
- **create_monitor(payload)** — проверяет, что URL относится к выбранной площадке, и создаёт мониторинг; повторный URL возвращает конфликт.
- **get_monitors()** — отдаёт все записи мониторинга.
- **export_monitors()** — формирует CSV в UTF-8 с BOM для корректного открытия в табличных редакторах.
- **patch_monitor(monitor_id, payload)** — меняет активность или интервал проверки.
- **remove_monitor(monitor_id)** — удаляет мониторинг товара.
- **get_monitor_history(monitor_id, limit)** — проверяет существование мониторинга и возвращает ценовые точки.
- **get_alerts(monitor_id, limit)** — возвращает все оповещения либо оповещения одного товара.

### src/parcers/base.py — общая модель данных

- **MAX_PROVIDER_LIMIT** — общий максимальный объём результатов от одного адаптера за один вызов.
- **SearchStatus** — состояния источника: READY, NO_RESULTS, ACCESS_REQUIRED, POLICY_RESTRICTED и ERROR.
- **Offer** — нормализованное предложение с площадкой, названием, ценой, валютой, URL, идентификатором, брендом, моделью, GTIN, наличием, изображением и данными карточки.
- **Offer.__post_init__()** — удаляет лишние пробелы и проверяет название, положительную конечную цену, код валюты из трёх букв и HTTPS URL.
- **ProviderResult** — ответ одного адаптера: статус, адрес поиска, предложения, сообщение и необязательный has_more, который отличает короткую неполную выдачу от конца каталога.
- **ProviderResult.to_dict()** — преобразует ответ, вложенные Offer и has_more в JSON-совместимый словарь.
- **SearchAdapter** — протокол адаптера; требует имя площадки и асинхронный метод search(query, limit).
- **DisabledAdapter** — базовый адаптер для отключённого источника. Он умеет построить прямую ссылку и сообщает, что автоматическая выдача не подключена.
- **DisabledAdapter.build_search_url(query)** — подставляет URL-кодированный запрос в шаблон площадки.
- **DisabledAdapter.search(query, limit)** — проверяет запрос и лимит, возвращает ProviderResult со статусом и причиной отключения.
- **normalize_title(value)** — нормализует Unicode, регистр, знаки препинания и пробелы в названии.
- **offer_group_key(offer)** — строит ключ сопоставления: корректный GTIN, затем бренд+модель, затем точное нормализованное название.

### src/parcers/service.py — координация поиска

- **PROVIDER_FETCH_CAP** — предельный размер выборки одного источника; совпадает с MAX_PROVIDER_LIMIT.
- **SEARCH_SESSION_TTL_SECONDS** — время хранения результата одной поисковой сессии: 600 секунд.
- **MAX_SEARCH_SESSIONS** — верхняя граница числа поисковых сессий в памяти: 100.
- **MarketplaceSearchService** — объединяет адаптеры, тайм-ауты, результаты и постраничную выдачу.
- **MarketplaceSearchService.__init__(adapters, provider_timeout)** — использует переданные адаптеры или создаёт Ozon, WB и Яндекс Маркет; задаёт тайм-аут источника и кэш сессий.
- **MarketplaceSearchService._merge_provider_offers(existing, incoming)** — объединяет результаты одного источника по external_id или URL, заменяя обновившуюся запись и сохраняя порядок.
- **MarketplaceSearchService.parse_product(marketplace, product_url)** — выбирает адаптер по имени площадки и получает разобранную публичную карточку, если адаптер это поддерживает.
- **MarketplaceSearchService._search_one(adapter, query, limit)** — запускает один адаптер с общим тайм-аутом.
- **MarketplaceSearchService.search(query, limit, offset, session_id)** — параллельно запрашивает источники; сохраняет успешные префиксы выдачи сессии; отдельно отображает ошибки; объединяет дубли только между площадками; сортирует предложения по валюте и цене; возвращает страницу, has_more, exact_total и retryable. Учитывает явный has_more адаптера вместо предположения по числу карточек. Короткий ответ с признаком продолжения оставляет кнопку повтора; на чистый пустой ответ без продолжения помечает источник завершённым.

## Парсеры и адаптеры

### src/parcers/public_html.py — Schema.org, JSON-LD и Microdata

- **_JsonLdParser** — HTML-парсер блоков JSON-LD.
- **_JsonLdParser.__init__()** — создаёт буфер текущего script и список документов.
- **_JsonLdParser.handle_starttag(tag, attrs)** — начинает сбор script с типом ld+json.
- **_JsonLdParser.handle_data(data)** — добавляет текст в активный блок JSON-LD.
- **_JsonLdParser.handle_endtag(tag)** — сохраняет собранный JSON при закрытии script.
- **_walk(value)** — рекурсивно проходит списки и полезные поля Schema.org, например @graph и itemListElement.
- **_as_text(value)** — получает текст из строки, списка или объекта с name, @id или url.
- **_number(value)** — извлекает однозначное положительное число из строковой цены или рейтинга.
- **_review_total(value)** — получает целое количество отзывов из текстового значения.
- **_clean_description(value)** — нормализует пробелы и ограничивает длину описания.
- **_product_metadata(item)** — извлекает описание, рейтинг, число отзывов, характеристики и до десяти текстовых отзывов из Schema.org Product.
- **_price_from_offer(offer)** — проверяет price, lowPrice и priceSpecification и возвращает первую однозначную положительную цену.
- **_MicrodataProductParser** — собирает Product-разметку из HTML-атрибутов itemprop/itemscope.
- **_MicrodataProductParser.__init__()** — инициализирует текущую карточку и стек тегов.
- **_MicrodataProductParser.handle_starttag(tag, attrs)** — открывает новую Product-карточку, записывает атрибуты и сохраняет вложенные свойства в стеке.
- **_MicrodataProductParser.handle_data(data)** — добавляет текст к текущему itemprop.
- **_MicrodataProductParser.handle_endtag(tag)** — закрывает тег и удаляет соответствующую часть стека.
- **_MicrodataProductParser.close()** — завершает HTML-разбор и сохраняет последнюю Product-карточку.
- **PublicHtmlSearchAdapter.__init__(...)** — принимает площадку, шаблон поиска, разрешённые хосты, тайм-аут и необязательный ResilientFetcher.
- **PublicHtmlSearchAdapter._valid_marketplace_url(value, base)** — разрешает только HTTPS-ссылки на хост площадки или его поддомен.
- **PublicHtmlSearchAdapter._extract(html, page_url, limit)** — сначала разбирает JSON-LD Product/Offer, затем при отсутствии карточек пробует Microdata; проверяет цены и URL.
- **PublicHtmlSearchAdapter._extract_product(html, page_url)** — среди разобранных записей выбирает карточку с тем же путём, что и у запрошенной страницы.
- **PublicHtmlSearchAdapter._fetch_public_page(url)** — получает страницу через общий ResilientFetcher и повторно проверяет конечный URL после редиректа.
- **PublicHtmlSearchAdapter.parse_product(product_url)** — проверяет домен ссылки, загружает публичную карточку и возвращает Offer либо None.
- **PublicHtmlSearchAdapter.search(query, limit)** — формирует ссылку поиска, загружает страницу и возвращает ProviderResult; внутренний предел адаптера — MAX_PROVIDER_LIMIT.

- **_ozon_review_entries(widget)** — нормализует доступные публичные отзывы в имя, дату, оценку и текст.
- **extract_ozon_product(html, page_url)** — читает встроенное состояние карточки Ozon: название, цену, SKU, фото, описание, рейтинг, число отзывов, характеристики и тексты отзывов.
- **extract_ozon_embedded(html, page_url, allowed_url)** — находит виджеты tileGridDesktop/searchResults, проверяет домен карточек и возвращает предложения.

### Адаптеры маркетплейсов

**src/parcers/ozon.py**

- **OzonAdapter** — специализированный публичный HTML-адаптер Ozon.
- **OzonAdapter._extract(html, page_url, limit)** — сначала использует карточки из встроенного JSON состояния Ozon, а при пустом результате — общий JSON-LD/Microdata разбор.
- **OzonAdapter._extract_product(html, page_url)** — берёт сведения из встроенных виджетов карточки и дополняет полями общего Schema.org-разбора.
- **OzonAdapter.from_env()** — создаёт адаптер из разрешённого JSON-фида, если настроен MULTIMARKET_OZON_FEED_URL; иначе использует публичный HTML.

**src/parcers/wb.py**

- **WildberriesAdapter** — HTML-адаптер публичного поиска Wildberries.
- **WildberriesAdapter._extract(html, page_url, limit)** — сначала использует массив товаров во встроенном состоянии WB, затем Schema.org JSON-LD/Microdata.
- **WildberriesAdapter._extract_product(html, page_url)** — находит артикул в пути /catalog/<id>/, выбирает совпадающую встроенную запись и дополняет её общими полями.
- **WildberriesAdapter.from_env()** — выбирает настроенный разрешённый фид либо публичный HTML-адаптер.

**src/parcers/ym.py**

- **_YandexProductStateParser** — читает видимые data-auto поля открытой карточки Яндекс Маркета.
- **_YandexProductStateParser.__init__()** — создаёт стек тегов, активные текстовые захваты и словарь результата.
- **_YandexProductStateParser.handle_starttag(tag, attrs)** — отслеживает вложенность и начинает захват целевого data-auto элемента.
- **_YandexProductStateParser.handle_data(data)** — добавляет текст к активным полям.
- **_YandexProductStateParser.handle_endtag(tag)** — завершает совпавшие поля и закрывает уровни стека.
- **_YandexSearchCardsParser** — извлекает заголовки, цены, URL и изображения из публичных карточек поиска.
- **_YandexSearchCardsParser.__init__()** — создаёт стек тегов, список карточек и буферы текущей карточки.
- **_YandexSearchCardsParser.handle_starttag(tag, attrs)** — начинает карточку searchOrganic, включает сбор заголовка/цены и находит ссылку с изображением.
- **_YandexSearchCardsParser.handle_data(data)** — накапливает текст для активного поля карточки.
- **_YandexSearchCardsParser.handle_endtag(tag)** — завершает поля и закрывает карточку при выходе из контейнера.
- **_YandexSearchCardsParser.close()** — закрывает HTML-парсер и сохраняет последнюю карточку.
- **_YandexSearchCardsParser._finish_card()** — добавляет текущую карточку в список и очищает временные буферы.
- **MAX_SEARCH_PAGES** — предел в 50 публичных страниц на один поиск Яндекс Маркета, достаточный для внутреннего лимита до 200 карточек при типичном размере страницы.
- **YandexMarketAdapter._extract(html, page_url, limit)** — разбирает публичные карточки data-auto, нормализует цену и URL, удаляет повторы; при необходимости пробует общий JSON-LD разбор.
- **YandexMarketAdapter._is_challenge_page(page_url, html)** — распознаёт известный адрес или маркеры публичной страницы проверки и возвращает признак ограничения.
- **YandexMarketAdapter.search(query, limit)** — загружает страницу поиска и последовательно пробует до MAX_SEARCH_PAGES страниц, пока не получит нужное число уникальных карточек, не встретит конец выдачи или публичную страницу проверки. При проверке/сетевом сбое возвращает найденные товары с has_more=True, чтобы интерфейс не принимал частичный результат за конец каталога; CAPTCHA не решает.
- **YandexMarketAdapter._extract_product(html, page_url)** — читает название и цену из data-auto и дополняет результат Schema.org-полями.
- **YandexMarketAdapter.from_env()** — использует разрешённый фид при наличии URL, иначе создаёт HTML-адаптер.

### Партнёрские и совместимые адаптеры

**src/parcers/feed.py**

- **JsonFeedAdapter** — преобразует лицензированный JSON-фид в общие Offer.

- **JsonFeedAdapter.search(query, limit)** — вызывает фид с параметрами q/limit, добавляет серверный токен при настройке и маппит полученные записи.

**src/parcers/wb_adapter.py**

- **RecordSource** — тип асинхронной функции, которая возвращает записи разрешённого источника WB.
- **_read(record, key, default)** — читает поле из словаря или объекта.
- **_rubles_from_kopecks(value)** — преобразует положительную сумму копеек в рубли.
- **_wb_specifications(value)** — преобразует словарь, список или JSON-строку характеристик в пары name/value.

- **WildberriesAdapter** — совместимый адаптер, который принимает записи от явно переданного разрешённого источника; сам сетью не пользуется.
- **WildberriesAdapter.__init__(source)** — сохраняет необязательный callback источника.
- **WildberriesAdapter.from_record_source(source)** — создаёт экземпляр и проверяет, что source вызываем.
- **WildberriesAdapter.search(query, limit)** — если callback отсутствует, возвращает состояние отключённого источника; иначе получает записи и преобразует их через wb_record_to_offer.

### src/parcers/transport.py — получение HTML

- **CHROME_MAJOR, BLOCK_STATUSES, RETRY_STATUSES, MAX_RETRY_AFTER, CHALLENGE_MAX_CHARS, CHALLENGE_MARKERS** — настройки профилей, повторов и распознавания страниц проверки.
- **BlockedError.__init__(message, status_code)** — сохраняет причину и необязательный HTTP-код страницы проверки.
- **_chrome_headers(platform, platform_hint)** — формирует согласованный набор обычных браузерных HTTP-заголовков.
- **browser_profiles()** — возвращает профили заголовков Windows и macOS.
- **_env_number(name, default, minimum, cast)** — читает число из переменной окружения и проверяет минимальное значение.
- **parse_proxy_urls(raw)** — разбирает список HTTP(S) адресов прокси без вывода учётных данных в ошибках.
- **FetcherConfig** — настройки пауз, повторов, кэша, тайм-аутов, прокси и необязательного клиента.
- **FetcherConfig.from_env()** — собирает FetcherConfig из переменных MULTIMARKET_*.
- **FetchedPage** — результат сетевого запроса: конечный URL, HTML-текст и HTTP-статус.
- **ProxyPool.__init__(proxies, cooldown, clock)** — сохраняет список прокси и таймер их восстановления.
- **ProxyPool.__len__()** — возвращает количество настроенных адресов.
- **ProxyPool.acquire()** — выдаёт следующий доступный прокси; если все на паузе, выбирает тот, что восстановится раньше.
- **ProxyPool.report_failure(proxy)** — ставит использованный прокси на период охлаждения.
- **ProxyPool.report_success(proxy)** — снимает период охлаждения после успешного запроса.
- **_default_client_factory(proxy, headers, cookies, timeout)** — создаёт стандартный httpx AsyncClient.
- **_CurlClient.__init__(...)** — создаёт необязательную сессию curl_cffi с заданными параметрами.
- **_CurlClient.cookies** — преобразует cookies сессии в контейнер httpx.
- **_CurlClient.__aenter__()** — поддерживает использование клиента в async with.
- **_CurlClient.__aexit__(*exc_info)** — закрывает curl_cffi сессию.
- **_CurlClient.get(url)** — загружает страницу и переводит ответ или сетевую ошибку в типы httpx.
- **make_client_factory(impersonate)** — выбирает фабрику httpx или, если настроено, curl_cffi; возвращает ошибку с инструкцией, если библиотека отсутствует.
- **factory(proxy, headers, cookies, timeout)** — вложенный фабричный callback, создающий _CurlClient для выбранного профиля.
- **_retry_after_seconds(response)** — читает числовой или HTTP-date заголовок Retry-After и ограничивает ожидание сверху.
- **looks_like_challenge(text)** — ищет маркеры страницы проверки только в небольшом ответе, чтобы не принимать обычную длинную страницу за CAPTCHA.
- **ResilientFetcher.__init__(...)** — подготавливает конфигурацию, клиент, часы, случайный генератор, пул прокси, cookies и кэш.
- **ResilientFetcher._throttle(host)** — резервирует следующий временной слот запроса к хосту с небольшим случайным интервалом.
- **ResilientFetcher._backoff(attempt)** — рассчитывает растущую паузу между повторами.
- **ResilientFetcher._headers_for(host)** — выбирает согласованный для хоста профиль и применяет настроенный User-Agent.
- **ResilientFetcher._reset_session(host, proxy)** — удаляет cookies после ограничения и переключает профиль.
- **ResilientFetcher._cache_get(url)** — возвращает свежий сохранённый ответ либо удаляет просроченный.
- **ResilientFetcher._cache_put(url, page)** — сохраняет ответ с TTL и ограниченным размером кэша.
- **ResilientFetcher._pause(delay, deadline)** — ждёт перед повтором только если ожидание укладывается в общий срок запроса.
- **ResilientFetcher._label(proxy)** — формирует безопасную метку direct/proxy-host без логирования логина и пароля.
- **ResilientFetcher.fetch(url)** — получает публичную страницу с кэшированием и ограничением частоты; обрабатывает статус, Retry-After, конечный срок, временные сетевые ошибки и страницы проверки.
- **get_shared_fetcher()** — возвращает общий экземпляр ResilientFetcher для всех адаптеров.

## Мониторинг цен

### src/parcers/monitoring.py

- **BACKEND_DIR, DB_PATH** — путь к базе SQLite; DB_PATH можно заменить переменной MULTIMARKET_DB_PATH.
- **_now()** — возвращает текущее время UTC.
- **_connect()** — контекстный менеджер подключения к SQLite с внешними ключами, commit/rollback и закрытием соединения.
- **init_db()** — создаёт таблицы мониторинга, снимков цен, оповещений и индексы.
- **create_monitor(...)** — создаёт запись с первым сроком проверки.
- **_monitor_dict(row)** — преобразует строку SQLite в словарь и active в boolean.
- **list_monitors()** — отдаёт мониторинги от новых к старым.
- **get_monitor(monitor_id)** — возвращает один мониторинг или None.
- **update_monitor(monitor_id, active, interval_seconds)** — обновляет переданные поля и пересчитывает следующий запуск при смене интервала.
- **delete_monitor(monitor_id)** — удаляет запись и связанные точки/оповещения по каскаду.
- **due_monitors(limit)** — возвращает активные мониторинги, срок которых наступил.
- **record_check(...)** — сохраняет цену и статус, рассчитывает следующий запуск, создаёт оповещение при изменении цены не меньше порога; при отсутствии цены не выдумывает снимок.
- **send_telegram_alert(alert, monitor)** — отправляет Telegram-сообщение, если в окружении заданы токен и chat id; сетевой сбой не ломает мониторинг.
- **price_history(monitor_id, limit)** — возвращает выбранные точки цены в хронологическом порядке.
- **list_alerts(monitor_id, limit)** — возвращает последние оповещения по всем товарам или одному мониторингу.
- **monitoring_loop(search_service, stop_event, interval_seconds)** — опрашивает due_monitors, получает текущую публичную цену через parse_product или поиск, записывает результат, отправляет созданные оповещения и ждёт следующий цикл.

## Интерфейс

### static/app.js — поиск, сравнение и карточка товара

- **element(tag, className, text)** — создаёт DOM-элемент с классом и безопасно добавленным текстом.
- **message(node, text)** — показывает или скрывает уведомление и выставляет его текст.
- **productsWord(n)** — выбирает правильную русскую форму слова «товар».
- **newSearchSessionId()** — генерирует уникальный идентификатор сессии для повторных страниц поиска.
- **money(value, currency)** — форматирует сумму по локали ru-RU.
- **renderProviders(providers)** — показывает состояние каждого источника и его ссылку на поиск.
- **renderOffers(products, query, append)** — отрисовывает карточки и предложения, минимальные цены, кнопки подробностей, перехода на площадку и создания мониторинга.
- **renderDetailFields(data, fallbackOffer)** — обновляет описание, рейтинг, число отзывов, характеристики и список доступных отзывов в модальном окне.
- **openProductDetails(offer)** — показывает быстрые данные карточки, запрашивает подробности у API и игнорирует устаревший ответ при быстром переключении товара.
- **fetchPage(offset, append, sequence)** — отправляет API-запрос с активной поисковой сессией, обновляет результаты и состояние кнопки продолжения/повтора.
- **runSearch(query)** — начинает новую сессию, очищает старую выдачу, показывает индикатор загрузки и запускает первую страницу.
- **Обработчик кнопки закрытия** — закрывает модальное окно товара.
- **Обработчик отправки формы** — начинает поиск по введённому запросу.
- **Обработчик популярного запроса** — запускает поиск по выбранной подсказке.
- **Обработчик «Показать ещё»** — запрашивает текущий nextOffset; при временной ошибке оставляет то же смещение и позволяет повторить.
- **Обработчик «Следить» внутри карточки** — создаёт мониторинг для выбранного предложения и показывает его результат.

### static/monitoring.js — страница мониторинга

- **el(tag, cls, text)** — создаёт элемент и безопасно задаёт текст.
- **showNote(text)** — показывает или очищает блок ошибок/сообщений.
- **priceText(value, currency)** — форматирует текущую цену или текст «Цена ещё не получена».
- **loadMonitors()** — загружает мониторинги и строит карточки с кнопками истории, паузы/продолжения, удаления и перехода к товару.
- **Обработчик «Пауза/Продолжить»** — обновляет active у мониторинга и перезагружает список.
- **Обработчик «Удалить»** — удаляет мониторинг и перезагружает список.
- **Обработчик «Обновить»** — вручную запускает loadMonitors.

### static/history.js — история цен

- **el(tag, cls, text)** — создаёт DOM-элемент и добавляет текст.
- **showNote(text)** — управляет сообщением об ошибке.
- **formatPrice(value, currency)** — форматирует цену по ru-RU.
- **chart(points)** — строит SVG-график по точкам цены; при одной точке возвращает пустой график.
