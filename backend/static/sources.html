Настройка источников для разработчиков
О кодах 403 и 498

Это ответ площадки на автоматический запрос. Если сервер не отдаёт страницу с карточками, переписывание извлекателя не создаст реальные товары. Для стабильной выдачи подключи разрешённый API или партнёрский JSON-фид.

O

Ozon

Обычный публичный поиск может быть ограничен. Для фида используй серверные переменные:

MULTIMARKET_OZON_FEED_URLMULTIMARKET_OZON_FEED_TOKEN
WB

Wildberries

Если публичный запрос возвращает 498, подключи разрешённый фид:

MULTIMARKET_WB_FEED_URLMULTIMARKET_WB_FEED_TOKEN

Для записей в формате WB Item:

MULTIMARKET_WB_FEED_FORMAT=wb_records
Я

Яндекс Маркет

Также поддерживается подключение партнёрского фида:

MULTIMARKET_YM_FEED_URLMULTIMARKET_YM_FEED_TOKEN
КАК ПОДКЛЮЧИТЬ

Настройка фида

  1. Возьми HTTPS URL и токен у официального или разрешённого поставщика данных.
  2. Скопируй backend/.env.example в backend/.env и заполни переменные нужной площадки.
  3. Перезапусти приложение. Токены используются только сервером и не показываются в браузере.

Фид должен принимать параметры q и limit и возвращать массив offers. К каждой записи нужны title, price, currency и ссылка на товар на соответствующей площадке. Подробный пример есть в документации проекта.
