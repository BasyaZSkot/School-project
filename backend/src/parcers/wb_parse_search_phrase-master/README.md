# Локальный режим: первые 200 товаров

Обычный запуск `main.py` запрашивает только страницы 1 и 2 обычной выдачи WB, без ценовых фильтров и предварительного поиска диапазонов. Товары сохраняются в порядке выдачи, дубли по артикулу удаляются. В обработку фотографий, цен кошелька и Excel попадает не более 200 товаров. Если источник вернул меньше, результат будет меньше 200. Дополнительные страницы не загружаются.

Это самостоятельный скрипт с выгрузкой в Excel; он пока не подключён к веб-поиску MultiMarket. `get_price_range.py` сохранён как исходный модуль, но обычный запуск его не использует. Реальный доступ к WB зависит от ответа площадки.

Ниже сохранено описание исходного проекта; упоминания сбора всей выдачи относятся к исходной версии, а не к текущему ограниченному режиму.

# Wildberries Parser

Инструмент для **автоматического сбора всех товаров Wildberries по поисковой фразе**
с выгрузкой результатов в **Excel файл**.

Парсер реализует **обход ограничения Wildberries на 50–60 страниц выдачи**, поэтому можно собрать **практически все товары по запросу**, а не только первые страницы.

Проект создан в образовательных целях и подробно разобран в серии видео на YouTube.

---

# Возможности

- 🔎 Сбор товаров по **поисковому запросу**
- 📄 **Обход ограничения страниц** Wildberries
- 📊 Выгрузка данных в **Excel**
- ⚡ **Быстрый асинхронный парсинг**
- 🧩 Простой запуск без сложной настройки
- 🐍 Написан на **Python 3.12+**

 - Рейтинг продавца

 - Общее название предмета

## Установка

Требования:

- Python **3.12+**

Склонируйте репозиторий:

```bash
git clone https://github.com/yourusername/wildberries-parser.git
cd wildberries-parser
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Измените поисковую фразу (в main.py) на необходимую и запустите парсер:

```bash
python main.py
```
