# Wildberries Parser

Инструмент для сбора каталожных данных по поисковой фразе с выгрузкой результатов в Excel.

> Важно: этот пример использует внутренние, недокументированные интерфейсы Wildberries и браузерную сессию. Он не подключён к MultiMarket и не должен запускаться как часть агрегатора без разрешённого источника данных.

## Возможности примера

- обработка поискового запроса;
- модели товаров и валидация полей;
- обработка цен, изображений и выгрузка в Excel;
- асинхронная организация задач.

## Установка

Требуется Python 3.12+.

```bash
python -m pip install -r requirements.txt
python main.py
```

Перед запуском проверь правила и условия Wildberries и используй только разрешённый доступ.

## MultiMarket

Для интеграции в агрегатор используется отдельный безопасный слой преобразования записей в общий формат `Offer`:

`backend/src/parcers/wb_adapter.py`

Сетевой транспорт примера не запускается автоматически из MultiMarket.
