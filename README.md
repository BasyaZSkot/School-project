2. Общая описательная часть
Проект представляет собой веб-платформу,
которая объединяет товары с различных популярных маркетплейсов (Ozon, Wildberries,
Яндекс Маркет и др.) в едином интерфейсе. Сайт позволяет пользователю
искать нужный товар сразу на всех площадках одновременно,
сравнивать цены, рейтинги и условия доставки. Backend разрабатывается с использованием
фреймворка Java Spring Boot (или Python FastAPI).
4. Ключевые возможности и функции планируемой программы
 * Единый поиск: ввод запроса в одну поисковую строку и получение результатов сразу со всех подключенных маркетплейсов.
 * Сводная карточка товара: отображение цен, наличия, рейтинга и сроков доставки одного и того же товара у разных продавцов и площадок на одном экране.
 * Сортировка и фильтрация: отбор предложений по минимальной цене, лучшим отзывам, скорости доставки или конкретному маркетплейсу.
 * Избранное и отслеживание скидок: сохранение товаров в личном кабинете и получение уведомлений при снижении цены на любой из площадок.
 * Быстрый переход к покупке: прямая ссылка на страницу выбранного маркетплейса с самым выгодным предложением для оформления заказа.
