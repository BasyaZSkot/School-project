# Подключение почты и персональных уведомлений

Избранное, сравнение, синхронизация доставки и уведомления внутри сайта работают без сторонних ключей. Для писем нужен SMTP, для Telegram — отдельный бот. Секреты добавляйте только в `backend/.env`; этот файл исключён из Git. В чат или GitHub их отправлять не нужно.

## 1. Почта

У почтового провайдера узнайте SMTP-сервер, порт и способ подключения. Получите пароль приложения для почтового клиента, если провайдер его требует. Заполните `backend/.env`:

```env
MULTIMARKET_SMTP_HOST=адрес_SMTP_сервера
MULTIMARKET_SMTP_PORT=587
MULTIMARKET_SMTP_USERNAME=логин
MULTIMARKET_SMTP_PASSWORD=пароль_приложения
MULTIMARKET_SMTP_FROM=MultiMarket <ваш_адрес_отправителя>
MULTIMARKET_SMTP_SECURITY=starttls
MULTIMARKET_PUBLIC_URL=http://127.0.0.1:8000
```

Для порта 465 обычно используется `MULTIMARKET_SMTP_SECURITY=ssl`; окончательные значения берите у своего провайдера. Передача без шифрования разрешена приложением только локальному тестовому SMTP-серверу.

`MULTIMARKET_PUBLIC_URL` — адрес вашего сайта без пути, параметров и завершающего `/`. Для локального запуска используйте тот же адрес, по которому открываете сайт: `http://127.0.0.1:8000` или `http://localhost:8000`. После размещения в интернете укажите адрес с HTTPS, например `https://your-domain.example`. Приложение использует эту настройку для ссылок в письмах.

Остановите и снова запустите сервер в PyCharm. Затем:

1. Откройте «Аккаунт» → «Отправить письмо подтверждения».
2. В полученном письме откройте ссылку и нажмите «Подтвердить почту».
3. Вернитесь в аккаунт, обновите страницу и включите канал Email.
4. Для проверки восстановления выйдите, выберите «Забыли пароль?» и запросите письмо.

Ссылка подтверждения действует 24 часа, восстановления — 30 минут. Каждая используется один раз; новое письмо заменяет предыдущую ссылку того же назначения. Повторное письмо можно запросить через минуту. После смены пароля старый пароль и прежние сеансы перестают действовать. Для аккаунтов Google/Яндекс восстановление пароля выполняется у провайдера; локальный пароль им не назначается.

Без SMTP сайт прямо сообщает, что отправка писем недоступна. Регистрация, вход, избранное и уведомления на сайте при этом остаются доступны; неподтверждённая почта не используется для ценовых рассылок.

## 2. Telegram

1. Откройте официальный [@BotFather](https://t.me/BotFather) в Telegram.
2. Создайте отдельного бота командой `/newbot` и получите его токен.
3. Добавьте токен в `backend/.env`:

```env
MULTIMARKET_TELEGRAM_BOT_TOKEN=токен_вашего_бота
```

4. Перезапустите сервер.
5. На сайте откройте «Аккаунт» → «Уведомления» → «Подключить Telegram».
6. Перейдите по появившейся ссылке, нажмите «Начать» в личном чате с ботом и вернитесь на сайт.
7. Нажмите «Проверить подключение» и сохраните выбранные каналы.

Ссылка подключения действует 10 минут и подходит только для вашего аккаунта. Один личный чат нельзя одновременно подключить к двум аккаунтам. В настройках можно отключить привязку; команда `/stop` в боте выключает отправку в Telegram.

Бот запускается внутри приложения: отдельное окно или публичный адрес для webhook не требуются. Используйте бота без действующего webhook и другого одновременно работающего обработчика. Существующий webhook приложение не удаляет. Старый `MULTIMARKET_TELEGRAM_CHAT_ID` для персональных уведомлений не нужен: получатель определяется по подтверждённой привязке пользователя.

Документация Telegram: [подключение по ссылке](https://core.telegram.org/bots/features#deep-linking), [получение сообщений](https://core.telegram.org/bots/api#getupdates).

## 3. Правило для товара

В поиске нажмите «Следить за ценой». В «Моих товарах» раскройте «Цена и уведомления»:

- **Цена не выше заданной:** укажите сумму и валюту. Уведомление появится, когда цена достигнет цели, в том числе при первой проверке. Пока цена остаётся ниже цели, повторов при каждой проверке нет; после роста выше цели новое снижение может сработать снова.
- **Изменение на процент:** задайте порог относительно предыдущей успешной проверки и выберите снижение либо снижение и рост. При смене валюты ложное сравнение не выполняется.
- Выберите период проверки и каналы: сайт, Email, Telegram. У уже отслеживаемых товаров можно изменить каналы отдельно; настройки аккаунта служат значениями по умолчанию для новых товаров.

Проверки выполняются, пока запущен сервер. На странице «Уведомления» видны события, отметка прочтения и состояние отправки по внешним каналам. При временной ошибке отправка повторяется с задержкой, до пяти попыток. «Отправлено» означает принятие письма SMTP-сервером или успешный ответ Telegram, а не гарантированное прочтение получателем. После отключения канала неотправленные сообщения этого канала отменяются.

## 4. Избранное, сравнение и доставка

«В избранное» сохраняет товар в аккаунте без включения отслеживания. Сохранённая цена — снимок; актуальные условия уточняются при открытии карточки и в магазине. В избранном может быть до 200 товаров.

«Сравнить» добавляет до четырёх товаров в таблицу с выбором предложения и фильтром «Только различия». Список сравнения хранится в текущем браузере. Избранное, выбранный город и ПВЗ хранятся в аккаунте и восстанавливаются при входе на другом устройстве. При первом входе текущий гостевой выбор доставки переносится в новый аккаунт; выбор другого ранее вошедшего пользователя не переносится. При выходе возвращаются гостевые настройки браузера.

Разные память, RAM, цвет, комплектация, версия и состояние не считаются автоматически одним вариантом. Неизвестный параметр не подменяется предположением. Параметры SKU в ссылках учитываются при сохранении; регион и обычные рекламные метки не создают дубли. Сведения о продавце показываются, когда источник их передал. Наличие характеристик зависит от доступной разметки площадки.

Для карты Яндекса по-прежнему нужны отдельные `YANDEX_MAPS_API_KEY` и `YANDEX_SUGGEST_API_KEY`; они не связаны с SMTP или Telegram. Подключение карты не подтверждает доставку конкретного товара в выбранный ПВЗ.

## 5. Постоянные настройки сервера

Для сохранения сеансов между перезапусками задайте один постоянный `MULTIMARKET_SESSION_SECRET`. Его можно создать один раз:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Сохраните результат в `.env`. Для локального HTTP оставьте `MULTIMARKET_COOKIE_SECURE=false`, для публичного HTTPS установите `true`. Не используйте несколько процессов проверки цен для одной базы: стандартный запуск приложения рассчитан на один процесс сервера. Перед обновлением храните резервную копию `backend/data/multimarket.sqlite3`; новые таблицы и колонки добавляются автоматически при запуске.
